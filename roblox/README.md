# Битва Аур — версия для Roblox

## Как открыть игру
1. Скачай файл **`AuraBattle.rbxlx`** из этой папки (на GitHub: открой файл → кнопка «Download raw file»).
2. Открой его двойным кликом — запустится Roblox Studio (или в Studio: File → Open from File).
3. Нажми **Play** (F5). Интерфейс игры появится сразу.

## Сохранение прогресса
В Studio сохранение работает только если:
1. Игра опубликована: File → Publish to Roblox.
2. Включён доступ к API: Home → Game Settings → Security → **Enable Studio Access to API Services**.

Без этого можно играть и тестировать, просто прогресс не сохранится (в Output будет предупреждение — это нормально).

## Если что-то сломалось
Открой View → **Output**, скопируй красный текст ошибки и пришли его.

## Что есть в игре
- **Разломы**: 11 кейсов, рулетка, до 5 за раз, билеты с колеса (бесплатное открытие). 70% дропов окупают разлом, возврат ~97%.
- **Аура Кликер**: +150 монет за тап (не больше 12 тапов в секунду).
- **Битва аур**: 1 на 1 с ботом, готовые лобби или своя заявка до 6 разломов. Игрок побеждает в 70% битв.
- **Апгрейд**: до 8 аур → одна дороже, шанс до 80%, буст монетами, кнопки 75/50/25/10% и x2/x5/x10.
- **Контракт**: 3–10 аур → одна новая, шанс тира выше 70–100%.
- **Краш**: общий раунд для всех игроков сервера, автовывод, таблица игроков, в среднем ~3.5×, максимум 50×.
- **Колесо удачи** раз в сутки: монеты, удача +15% на час, скорость AFK x2, билеты, редкая FORTUNE.
- **Коллекция**, **инвентарь** с продажей, **промокоды** (`VANYA1M`; `INFINITY` — бесконечный баланс, работает только у владельца игры и в Studio).
- AFK-фарм: +100 монет каждые 10 секунд в игре. Лента редких дропов всех игроков сервера.
- Сохранение в DataStore, монеты в таблице игроков, английский/русский по языку Roblox.

## Где что настраивать
Все цифры — в `src/shared/Config.luau` (шансы, цены, таймеры, колесо, промокоды, боты, звуки).

## Звуки
По умолчанию используются встроенные звуки Roblox (`rbxasset://sounds/...`). Если какой-то не играет или не нравится —
найди звук в Studio: Toolbox → Audio, скопируй его id и впиши в `Config.SOUNDS` (например `tick = "rbxassetid://123456"`).

## Как вставить картинки
Картинки загружаются через Asset Manager в Studio, после загрузки у каждой будет id вида `rbxassetid://123456`.
Впиши его в `src/shared/Config.luau`: поле `image` у ауры или разлома, `CLICKER_IMAGE` — для кликера.

## Для разработки (необязательно)
Проект собирается инструментом [Rojo](https://rojo.space): `rojo build default.project.json -o AuraBattle.rbxlx`.
